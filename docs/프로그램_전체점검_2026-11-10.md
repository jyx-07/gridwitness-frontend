## 아직 완료로 선언할 수 없는 항목

- **실제 브라우저 + 연결된 UNO로 최신 배포본을 확인하는 현장 시험:** 브라우저 Web Serial 권한은 사용자 화면에서 눌러야 하며 이 점검 세션에서는 사용자 브라우저를 조작할 수 없었다. 같은 브라우저에서 장치 연결, 상태 질문, 물리적 선 분리 사건, 명령 사건을 각 한 번 확인해야 한다.
- **가로등 INA219 0x41:** 직전 하드웨어 점검 기록에서는 미인식이었다. 0x41이 실제로 보이고 주택/가로등 값을 각각 얻는지 재확인이 필요하다. 기존 정상 조합 00011의 허용 범위 이탈도 두 센서 연결 후 재측정한다.
- **API 접근 통제:** 운영 capabilities에서 `auth required=false`였고, 익명 읽기·쓰기 상태다. 실제 한전 적용에는 조직 인증과 권한·감사·보존 정책이 필요하다. 공개 프론트 코드에 공용 비밀 토큰을 넣는 방식은 인증 해결책이 아니다.
- **서버 수명:** 학교 API 서버의 인수인계 예정 만료일은 2026-11-20이다. 현재 백업은 같은 서버 안에 있으므로 다른 위치의 백업과 이전/연장 확인이 필요하다.
- **AI 실사용 평가:** 현재 LLM 검증은 대표 질문 몇 건의 통합 시험이다. 현장 질문·후속 대화·고장 구간/원인 보류·한국어 음성 인식 성능에 대한 독립 holdout 평가는 남아 있다. 모델 점수를 정확도나 확률로 발표하지 않는다.
